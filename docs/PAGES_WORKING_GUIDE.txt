1. AUTHENTICATION & ACCOUNT PAGES
================================================================================

1.1 Login Page (Login.jsx)
--------------------------
- Purpose: Authenticates shop owners and users into the BizManager platform.
- Step-by-Step Working:
  1. User opens the application and enters their registered email address and password.
  2. Clicking "Login" dispatches an HTTP POST request to /api/auth/login.
  3. The backend validates credentials, checks if the account is locked (5 failed attempts lock the account for 15 minutes), and generates a JWT token and HttpOnly device session cookie.
  4. On successful response, user credentials and token are stored in localStorage and Redux state.
  5. The user is automatically redirected to the main Dashboard.
  6. Includes quick navigation links to Registration and Forgot Password.

1.2 Registration Page (Register.jsx)
------------------------------------
- Purpose: Onboards new shop owners and registers their business.
- Step-by-Step Working:
  1. User fills in personal and business details: Owner Name, Email, Password, Shop Name, Address, and Phone Number (formatted for +92 Pakistan).
  2. Validates password strength (minimum 8 characters with uppercase, lowercase, numbers, and symbols) and matching passwords.
  3. Submitting the form dispatches /api/auth/register.
  4. Backend creates the User record along with a default Organization tenant scope.
  5. Automatically logs in the new owner and navigates them to the Dashboard.

1.3 Forgot Password Page (ForgotPassword.jsx)
---------------------------------------------
- Purpose: Initiates password reset procedure when a user forgets their credentials.
- Step-by-Step Working:
  1. User inputs their registered email address.
  2. Submitting sends a POST request to /api/auth/forgotpassword.
  3. If configured, an email containing a secure token link is dispatched.
  4. Displays a confirmation message instructing the user to check their email inbox.

1.4 Reset Password Page (ResetPassword.jsx)
-------------------------------------------
- Purpose: Allows users to set a new password using a secure reset token.
- Step-by-Step Working:
  1. User navigates via the link received in email containing the token parameter.
  2. User enters a new strong password and confirms it.
  3. Sends a PUT request to /api/auth/resetpassword/:token.
  4. Backend updates the encrypted password, invalidates the token, and redirects the user to Login.

1.5 Profile Settings Page (ProfileSettings.jsx)
-----------------------------------------------
- Purpose: Manages personal profile, shop credentials, tax numbers, and security options.
- Step-by-Step Working:
  1. Displays user profile details: Name, Email, Phone, Shop Name, GST/Tax Number, and Shop Address.
  2. Allows inline editing of business metadata.
  3. Provides a password update section requiring the current password and new password.
  4. Clicking "Save Changes" updates the User model via /api/users/profile.

2. CORE DASHBOARD & POS
================================================================================

2.1 Dashboard Page (Dashboard.jsx)
----------------------------------
- Purpose: Executive overview of real-time business performance, sales metrics, and inventory alerts.
- Step-by-Step Working:
  1. Upon load, fetches aggregated data for total sales, net revenue, total orders, dues, and low-stock items.
  2. Displays Key Performance Indicator (KPI) cards with percentage growth comparisons.
  3. Renders interactive sales trend charts (daily, weekly, monthly views).
  4. Shows a quick action menu for fast navigation to POS, New Invoice, Add Item, and Add Customer.
  5. Lists recent transaction histories and low stock alerts with quick reorder triggers.

2.2 Point of Sale Page (POS.jsx)
-------------------------------
- Purpose: Fast-paced retail billing screen optimized for barcode scanning and quick checkout.
- Step-by-Step Working:
  1. Left panel displays categorized inventory items with real-time stock badges and search/filter controls.
  2. User adds items to the cart by clicking or scanning barcodes with a USB/Bluetooth scanner.
  3. Cart calculates line items, subtotal, tax rates, item discounts, and overall bill discount.
  4. User selects or creates a Customer (Walk-in or registered customer).
  5. User selects Payment Method: Cash, Card, UPI/Online, or Split Payment.
  6. Clicking "Checkout" creates a completed Invoice, deducts item stock quantities automatically, updates customer dues if partial payment, and generates a printable thermal receipt.

3. INVENTORY MANAGEMENT
================================================================================

3.1 Inventory List Page (Inventory.jsx)
---------------------------------------
- Purpose: Master catalog of all stock items, stock valuation, and category filters.
- Step-by-Step Working:
  1. Fetches all inventory items for the user's organization from /api/items.
  2. Displays summary metrics: Total Stock Valuation (at cost price), Total Expected Revenue (at selling price), Total Items, and Out-of-Stock count.
  3. Search and filter by category, stock level (Low Stock, Out of Stock, In Stock), or barcode.
  4. Each item row displays SKU, Barcode, Category, Cost Price (Rs.), Selling Price (Rs.), Available Stock, and Actions.
  5. Quick actions include Edit Item, Delete Item, and Print Barcode.

3.2 Add Item Page (AddItem.jsx)
-------------------------------
- Purpose: Creates new inventory product records with pricing and stock rules.
- Step-by-Step Working:
  1. Form inputs: Product Name, SKU, Barcode, Category, Unit (kg, pcs, litre), Cost Price (Rs.), Selling Price (Rs.), Opening Stock, Low Stock Threshold, HSN Code, and Tax Rate (%).
  2. Automatically calculates estimated profit margin per unit and percentage.
  3. Form validation ensures positive pricing and unique SKU/Barcode within the organization.
  4. Submitting dispatches POST /api/items to create the database record.

3.3 Edit Item Page (EditItem.jsx)
---------------------------------
- Purpose: Updates existing product specifications, prices, or stock adjustments.
- Step-by-Step Working:
  1. Pre-fills form fields with current item data using the URL ID parameter.
  2. Allows modifying item price, category, unit, tax rules, or threshold parameters.
  3. Submitting sends a PUT request to /api/items/:id and redirects back to Inventory.

4. CUSTOMER MANAGEMENT
================================================================================

4.1 Customers List Page (Customers.jsx)

- Purpose: Directory of all registered customers with balances, dues, and transaction histories.
- Step-by-Step Working:
  1. Fetches customer list from /api/customers.

---------------------------------------
- Purpose: Registers a new customer into the system.
- Step-by-Step Working:
  1. Inputs: Customer Name, Phone Number, Email, Address, and Opening Balance/Dues.
  2. Validates phone format and prevents duplicate phone registration.
  3. Submitting sends POST /api/customers and updates the customer directory.

4.3 Edit Customer Page (EditCustomer.jsx)
-----------------------------------------
- Purpose: Edits existing customer details or contact info.
- Step-by-Step Working:
  1. Pre-populates customer data using URL parameter.
  2. Allows editing Name, Phone, Email, or Address.
  3. Submitting updates the customer via PUT /api/customers/:id.

4.4 Customer Detail Page (CustomerDetail.jsx)

4.5 Customers With Dues Page (CustomersWithDues.jsx)
---------------------------------------------------
- Purpose: Specialized view filtering only customers who have unpaid balances.
- Step-by-Step Working:
  1. Queries /api/customers with dues > 0.

  3. Features quick action buttons to Send WhatsApp Payment Reminders or Collect Payment.

4.6 Due Adjustment Page (DueAdjustment.jsx)
-------------------------------------------
- Purpose: Allows manual credit/debit adjustments or bad debt write-offs on customer accounts.
- Step-by-Step Working:
  1. User selects a Customer and chooses Adjustment Type (Add Due / Reduce Due / Write-off).
  2. User enters Amount (Rs.), Date, and Reason/Notes.
  3. Submitting posts an adjustment record and updates the customer's net balance.

6. SALES MANAGEMENT
================================================================================

6.1 Sales Invoice List (SalesInvoice.jsx / Invoice.jsx)
-------------------------------------------------------
- Purpose: Manages all billing sales invoices generated via POS or Manual Billing.
- Step-by-Step Working:
  1. Fetches list of all sales invoices with date range filters.
  2. Summary cards display Total Sales Volume, Total Paid, and Total Unpaid Amounts.
  3. Table lists Invoice #, Customer Name, Date, Payment Status (Paid, Unpaid, Partial), Total Amount (Rs.), and Actions.
  4. Actions include View Invoice, Download PDF, Send Receipt, or Cancel Invoice.

6.2 Invoice Detail Page (SalesInvoiceDetail.jsx / InvoiceDetail.jsx)
-------------------------------------------------------------------
- Purpose: Detailed printable view of a specific sales invoice.
- Step-by-Step Working:
  1. Displays business header, tax details, invoice number, and customer information.
  2. Itemized table showing Description, Quantity, Unit Rate (Rs.), Tax, Discount, and Total.
  3. Calculation breakdown: Subtotal, Total Tax, Bill Discount, Net Payable, Paid Amount, and Balance Due.
  4. Action buttons: Print Thermal Receipt, Download Standard PDF, Send via WhatsApp/Email.

6.3 Sales Orders (SalesOrder.jsx / SalesOrderList.jsx / SalesOrderDetail.jsx)
------------------------------------------------------------------------------
- Purpose: Creates and manages advance sales orders before goods delivery.
- Step-by-Step Working:
  1. User selects customer and adds items with promised delivery dates.
  2. Creates Sales Order record with status (Pending, Confirmed, Fulfilled, Cancelled).
  3. Detail view allows converting a confirmed Sales Order directly into a final Sales Invoice.

6.4 Estimates / Quotations (Estimate.jsx / EstimateList.jsx / EstimateDetail.jsx)
--------------------------------------------------------------------------------
- Purpose: Generates price quotes and proforma estimates for prospective buyers.
- Step-by-Step Working:
  1. User enters customer info, item details, and validity date.
  2. Generates quotation PDF document.
  3. When customer approves, single-click converts the Estimate into an active Sales Order or Invoice.

6.5 Delivery Challan (DeliveryChallan.jsx / DeliveryChallanList.jsx / DeliveryChallanDetail.jsx)
--------------------------------------------------------------------------------------------------
- Purpose: Generates dispatch documents for goods shipped without immediate payment demand.
- Step-by-Step Working:
  1. User creates a Delivery Challan detailing vehicle number, dispatch date, items, and quantities.
  2. Track delivery status (In Transit, Delivered).
  3. Convert delivered challans into finalized sales invoices upon confirmation.

6.6 Payment In (PaymentIn.jsx / PaymentInList.jsx / PaymentReceiptDetail.jsx)
-----------------------------------------------------------------------------
- Purpose: Records money received from customers against pending dues or advance payment.
- Step-by-Step Working:
  1. User selects Customer; system automatically displays outstanding invoices.
  2. User enters Amount Received (Rs.), Payment Mode (Cash, Bank Transfer, Cheque, Online), Date, and Reference Number.
  3. Allocates payment against specific unpaid invoices.
  4. Generates Payment Receipt document and updates customer's balance.

6.7 Sales Returns & Credit Notes (Return.jsx / ReturnedItems.jsx)
-----------------------------------------------------------------
- Purpose: Processes items returned by customers and issues refunds or credit notes.
- Step-by-Step Working:
  1. User selects original Invoice # and items being returned with reason.
  2. System restocks returned items automatically into inventory.
  3. Issues Credit Note or Cash Refund to customer and updates sales records.

7. PURCHASE MANAGEMENT
================================================================================

7.1 Purchase Orders (PurchaseOrderForm.jsx / PurchaseOrderList.jsx / PurchaseOrderDetail.jsx)
---------------------------------------------------------------------------------------------
- Purpose: Creates formal purchase orders to buy inventory from suppliers.
- Step-by-Step Working:
  1. User selects Supplier, adds required items, order quantities, expected rates, and delivery date.
  2. Tracks order status (Draft, Sent, Approved, Partial Received, Closed).
  3. Generates PO document to send to vendor.

7.2 Goods Received Notes (GRNForm.jsx / GRNList.jsx / GRNDetail.jsx)
--------------------------------------------------------------------
- Purpose: Records physical receipt of products at warehouse against Purchase Orders.
- Step-by-Step Working:
  1. Selects Purchase Order and verifies delivered quantities against ordered quantities.
  2. Records batch numbers, expiry dates (if applicable), and rejected quantities.
  3. Updates physical stock levels in inventory.

7.3 Purchase Bills & Invoices (PurchaseEntry.jsx / Bills.jsx / BillDetail.jsx)
--------------------------------------------------------------------------------
- Purpose: Enters vendor purchase bills into accounting system for inventory and accounts payable.
- Step-by-Step Working:
  1. User enters Vendor Bill #, Bill Date, Supplier, and itemized purchase rates, taxes, and freight charges.
  2. System updates inventory cost prices and creates supplier payable dues.
  3. Displays Bill Aging (0-30 days, 31-60 days, 60+ days) to manage vendor payment schedules.

7.4 Purchase Returns (PurchaseReturnFormNew.jsx / PurchaseReturnList.jsx / PurchaseReturnDetail.jsx)
----------------------------------------------------------------------------------------------------
- Purpose: Returns damaged or incorrect products back to suppliers.
- Step-by-Step Working:
  1. Selects Purchase Bill and items being returned.
  2. Deducts items from inventory stock.
  3. Creates Debit Note and reduces vendor payable balance.

7.5 Payment Out (PaymentOut.jsx / PaymentOutList.jsx / PaymentOutDetail.jsx)
-----------------------------------------------------------------------------
- Purpose: Records payments made to vendors/suppliers.
- Step-by-Step Working:
  1. Selects Supplier and inputs Amount Paid (Rs.), Payment Method, and Bank Account used.
  2. Settles selected pending purchase bills.
  3. Generates Payment Voucher receipt.

7.6 Expenses Page (Expenses.jsx)
--------------------------------
- Purpose: Tracks operational business expenses (Rent, Electricity, Salaries, Maintenance).
- Step-by-Step Working:
  1. User records expense date, category, amount (Rs.), payment mode, and attaches receipt image/file.
  2. Categorizes expenses into Fixed vs Variable operating costs.
  3. Feeds directly into Net Profit calculation in Financial Reports.
